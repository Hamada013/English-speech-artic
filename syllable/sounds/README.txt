Syllables recordings (General American English)
Save each recording in syllable/sounds/<consonant number>/ under the file name shown (m4a).
Until a file is there, the device voice says it. Then run: node scripts/build-offline.cjs
Say each syllable as written: ah as in father, ee as in see, oo as in moon. Hyphens are a tiny pause.
