Speech Sounds: recording list

Every word, syllable, phrase, sentence and story page the app says, 1361 recordings in all.

How to record. A quiet room; one clear, natural General American model per file, at a child-friendly pace; about half a second of silence before and after.

Files. Save each as .m4a (AAC) with the exact file name in the left column, in the folder named at the top of its part. Tick the box when done.

After adding files. Run node scripts/build-offline.cjs (and node words/scripts/build-pwa.cjs for words). Until a file is there, the device voice says it.
